## Product direction

The biggest opportunity is to make VoiceMate feel less like “a web app with voice features” and more like a **living assistant with a calm, premium interface**.

### 1. Make Talk the entire product center

Home, Memory, Settings, Skills, and Talk all exist separately — but everything should flow into Talk.

**Improve Talk further**

- Make the orb the emotional center.
- Keep all secondary UI hidden until needed.
- Show context, tools, and thinking only as small expandable affordances.
- Keep transcript clean and conversational.
- Make system messages subtle, like iOS call status text.

**Best direction:** The Talk screen should feel like Orb + Transcript + Composer + Minimal controls — not like a dashboard.

### 2. Make the orb feel truly alive

**Emotional states**

- Idle: calm, breathing, subtle eye movement.
- Listening: attentive, eyes slightly perked, glass gently active.
- Thinking: eyes look slightly up/side, slower pulse.
- Speaking: audio-reactive, more alive.
- Happy/tapped: squint/pop/glow.
- Confused: slight tilt, small blink.
- Error/offline: muted glow, softer movement.

**Personality micro-moments**

- User pauses → orb blinks and looks curious.
- User says “thank you” → orb smiles.
- VoiceMate processing a file → orb looks down/side like it is reading.
- User interrupts → orb quickly snaps attention back.

### 3. Make voice calls feel like FaceTime for AI

**Call states**

Instead of just “Live,” show: Connecting, Listening, You're speaking, Thinking, VoiceMate speaking, Interrupted, Call ended.

**Call timer**

Small, quiet text: `Live · 02:14`

**Controls (later)**

End, Mute, Keyboard/text, Context — keep it minimal.

### 4. Fix transcript into a premium live-caption experience

**User speech**

- Words appear as the user speaks.
- Corrections replace the same bubble.
- Finalized text gently settles.
- No duplicate partials.

**VoiceMate speech**

- Words appear in sync with speech.
- Current word subtly brightens.
- Completed reply becomes normal text.
- Long answers break into natural paragraph bubbles.

**Typography hierarchy**

- User message: blue iMessage bubble.
- Assistant spoken response: soft white/glass bubble.
- System event: tiny centered pill.
- Tool/action: small muted row or drawer item.
- Error: subtle red/amber status chip.

### 5. Make Skills feel like actual products

Each skill should have its own mini-experience:

| Skill | Should do |
|---|---|
| **Research** | Ask what to research if missing, search, summarize, show sources, offer short vs deep follow-up |
| **Daily briefing** | Use reminders, uploads, saved conversations, recent memory, due dates — lead with what matters first |
| **Pitch builder** | Guide idea → audience → goal → tone → draft pitch → rehearse mode |
| **Data analyst** | Detect CSVs, screenshots, tables, charts, anomalies, missing values; offer summary, trends, “What should I do?”, export report |
| **Meeting coach** | Practice mode: user speaks, VoiceMate listens without interrupting, then feedback on clarity, confidence, concision, stronger rewrite |

### 6. Make uploads feel magical

- Compact upload cards in Talk: `IMG_9277.PNG · Screenshot · Ready to discuss` with Ask / Summarize / Compare / Remove.
- Automatic first-pass understanding: title, type, summary, entities, suggested questions.
- Real OCR/PDF parsing: PDF text extraction, OCR for screenshots, DOCX extraction, CSV profiling, image captioning.

### 7. Make Memory trustworthy and user-controlled

- Memory types: personal preferences, uploaded files, conversation summaries, reminders/tasks, temporary context, saved facts.
- “VoiceMate wants to remember…” prompts with Remember / Not now / Edit.
- Memory search across memory, uploads, conversations.
- Source labels on every item: uploaded file, chat, reminder, voice call, manual note.

### 8. Make reminders actually useful

- Natural-language parsing: “Remind me tomorrow at 9 to call Alex” → text, due, channel, optional contact.
- Notification center: upcoming, overdue, completed.
- Real providers later: Twilio, SendGrid/Postmark, Google Calendar, webhooks — permissions explicit.

### 9. Make the interface more iOS-native

- Fewer visible panels, more bottom-sheet interactions, blurred glass sheets.
- Fewer labels, more icon + short title, progressive disclosure, animation restraint.
- Context as a small pill → tap opens bottom sheet.
- Settings as compact grouped cards; diagnostics hidden by default.
- Memory grouped by type with search; active context pinned.

### 10. Add a “Today” or “Dashboard” moment

Home should become useful before the user asks:

- Continue last conversation
- Active reminders
- Recent uploads
- Suggested next action
- Start live call
- Daily briefing

### 11. Make onboarding excellent

Short first-run flow:

1. Pick a voice.
2. Try saying something.
3. Upload a file/image.
4. Ask about it.
5. Set a reminder.

Skippable. Include sample tasks: summarize screenshot, coach pitch, daily briefing, set reminder, research with sources.

### 12. Improve reliability and honesty

Graceful error states for: mic blocked, backend offline, API key missing, realtime disconnected, TTS failed, upload too large, file unsupported.

Each should say what happened, what the user can do, and whether a fallback is active.

Connection diagnostics in Settings: backend, API key, realtime, browser mic, notifications, storage.

### 13. Technical improvements (highest priority)

- Real browser/E2E tests for Talk flows.
- Stronger realtime transcript handling.
- IndexedDB-first storage for uploads.
- PDF/OCR/DOCX extraction.
- Shared tool schema between client/server.
- Real streaming with tool calls hardened.
- Auth if deployed anywhere public.
- AudioWorklet instead of ScriptProcessorNode (started in v0.4).
- Better payload limits and file chunking.
- Provider abstraction for reminders/actions.

### 14. The biggest product unlock

VoiceMate should know what mode it is in, what context it has, what it is doing, and what it needs next — **without making the user manage panels**.

- Context appears when useful.
- Skills guide naturally.
- Voice feels alive.
- Memory is controllable.
- Tools ask permission.
- Errors are calm.
- UI stays minimal.

## Recommended build sequence

1. Bottom-sheet Context UI instead of inline panels *(started in v0.4)*
2. Better live call transcript/caption polish with active word highlight *(started)*
3. Skill workflow screens/prompts for Research, Pitch, Analyst, Coach
4. PDF/OCR/DOCX extraction
5. Memory review and memory categories
6. Real reminder parsing and notification center
7. Onboarding flow expansion
8. Home dashboard evolution *(started in v0.4)*
9. AudioWorklet realtime capture *(started in v0.4)*
10. Tests and deploy hardening

The product is moving in the right direction. The main thing now is **restraint**: fewer visible controls, more intelligence behind the scenes, and stronger moments where VoiceMate feels alive, aware, and useful.
