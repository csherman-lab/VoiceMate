Product direction Roadmap Open

The goal: feel less like a web app with voice features and more like a living assistant with a calm, premium interface.

1. Talk as the product center Shipped

  • Orb as emotional center; secondary UI hidden until needed.
  • Context, tools, and thinking as small expandable affordances.
  • Clean transcript; system messages like iOS call status text.

2. Make the orb truly alive Shipped

  • Clear states: idle, listening, thinking, speaking, happy, confused, error/offline.
  • Personality micro-moments: curious blink on pause, smile on thanks, reading look during file work.

3. FaceTime-style live calls Shipped

  • Explicit call states: connecting, listening, you're speaking, thinking, VoiceMate speaking, interrupted.
  • Subtle call timer, mute/speaker controls later, minimal core controls.

4. Premium live captions Shipped

  • User speech streams in with gentle settle; corrections in-place.
  • Assistant words sync with speech; typography hierarchy for user, assistant, system, tool, and error rows.

5. Skills as mini-products Shipped

  • Research: clarify, search, cite, offer short vs deep follow-up.
  • Briefing: reminders, uploads, memory, due dates — lead with what matters first.
  • Pitch, analyst, and coach modes with guided steps and practice/rehearse flows.

6. Magical uploads Shipped

  • Compact upload cards in Talk with ask, summarize, compare, remove actions.
  • Automatic first-pass understanding: title, type, summary, entities, suggested questions.
  • Real PDF text extraction, OCR, DOCX parsing, CSV profiling, image captioning.

7. Trustworthy memory Shipped

  • Memory types: preferences, uploads, conversation summaries, reminders, temporary context, saved facts.
  • “VoiceMate wants to remember…” prompts with Remember / Not now / Edit.
  • Memory search and source labels (upload, chat, call, manual note).

8. Useful reminders Shipped

  • Natural-language parsing (“tomorrow at 9 to call Alex”).
  • Notification center for upcoming, overdue, and completed items.
  • Real providers later: Twilio, SendGrid, calendar, webhooks — with explicit permissions.

9. More iOS-native UI Shipped

  • Fewer panels, more bottom sheets, blurred glass, progressive disclosure, animation restraint.
  • Memory grouped by type with search; diagnostics hidden by default.

10–12. Today, onboarding, reliability Shipped

  • Home evolves into Continue, reminders, uploads, suggested next action, daily briefing.
  • Onboarding: pick voice, try speaking, upload, ask, set reminder — all skippable.
  • Graceful errors for mic blocked, backend offline, key missing, realtime drop, TTS fail, bad uploads.
  • Connection diagnostics: backend, API key, realtime, mic, notifications, storage.

Recommended build order

  1. Bottom-sheet Context Done
  2. Live caption polish & active word highlight Done
  3. Skill workflow screens for Research, Pitch, Analyst, Coach Done
  4. PDF / OCR / DOCX extraction Done
  5. Memory review & categories Done
  6. Reminder parsing & notification center Done
  7. Onboarding flow expansion Done
  8. Home dashboard evolution Done
  9. AudioWorklet realtime capture Done
  10. E2E tests, IndexedDB uploads, auth, deploy hardening Next

Principle: fewer visible controls, more intelligence behind the scenes, stronger moments where VoiceMate feels alive, aware, and useful.
